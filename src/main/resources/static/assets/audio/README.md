# Audio Assets Guide for Memory Match Arcade

This directory can hold your optional custom `.mp3` or `.wav` sound files:

| File Name | Purpose | Recommended Tone |
|---|---|---|
| `flip.mp3` | Card Flip | Quick paper/card tap or whoosh (0.1s) |
| `match.mp3` | Match Found | Positive cheerful chime / bell chord |
| `nomatch.mp3`| Mismatch | Gentle double thud or muted buzz |
| `win.mp3` | Victory Fanfare | Celebratory trumpet or victory harp |
| `bgmusic.mp3`| Background Music | Chill lofi or 8-bit arcade ambient loop |

> **Note on Built-in Synthesizer:**
> If any of these audio files are missing, the game automatically uses its built-in Web Audio API synthesizer to dynamically generate pleasant chimes, whooshes, chords, and fanfares so the game sounds great out of the box with zero external dependencies!

### Free Royalty-Free Audio Sources:
- **Mixkit Free Sound Effects**: https://mixkit.co/free-sound-effects/game/
- **Freesound.org**: https://freesound.org (Search for: `card flip`, `game chime`, `win fanfare`)
- **Kenney.nl Audio Assets**: https://kenney.nl/assets/category:Audio
